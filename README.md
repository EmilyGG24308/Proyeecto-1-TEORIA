
## Descripción
1. Conversión de infix a postfix (Shunting Yard).
2. AFN (Construcción de Thompson).
3. AFD (Construcción de Subconjuntos).
4. AFD minimizado.
5. Simulación de `w` sobre el AFN y el AFD para determinar si `w` pertenece a L(r).

El programa lee un archivo de texto (`input.txt`) donde cada línea es una expresión regular distinta.

## Requisitos

- Python 3.10 o superior.
- [Graphviz](https://graphviz.org/download/) instalado en el sistema (el ejecutable `dot` debe quedar disponible en el PATH).
- Paquete de Python `graphviz` (`pip install graphviz`).

## Cómo ejecutar

```bash
py main.py
```
